# Hotkeys

Amethystora is built to be driven from the keyboard. `Super` is the key with the Windows or Command
logo on it. This list is also what `ame desktop keybindings` shows, and the Amethystora menu
(`Super+Alt+Space`) reaches most of what these keys do. Control's **Keyboard** page lists every shortcut, these and GNOME's,
and changes any of them.

## Tiling

The tiling puts the windows of a workspace side by side on a strip that scrolls to keep the focused one
in view. `Super` and an arrow moves between windows, adding `Ctrl` moves the window itself, adding
`Shift` goes to another monitor. These keys, and the monitor keys under Workspaces, are the tiling
layout's; the classic layout (`ame desktop layout classic`) has GNOME's own.

| Key | Action |
| --- | --- |
| `Super+Left` / `Right` / `Up` / `Down` | Focus the window in that direction |
| `Super+Ctrl+Left` / `Right` / `Up` / `Down` | Move the window in that direction |
| `Super+Home` / `Super+End` | The first / last window on the workspace |
| `Super+[` / `Super+]` | Slide the strip; focus goes to the window most in view when you let go of `Super` |
| `Super+R` / `Super+Alt+R` | Step the width through 38%, 50% and 62% of the screen less its margins / back |
| `Super+Shift+R` / `Super+Alt+Shift+R` | Step the height of a window in a column / back |
| `Super` and `+` / `-` | Widen / narrow the window a step; with `Shift` as well, its height |
| `Super+F` | Fill the width of the screen, and back |
| `Super+C` | Centre the window |
| `Super+I` | Pull the window on the right into this column |
| `Super+O` / `Super+Shift+O` | Push the bottom / this window out into a column of its own |
| `Super+T` | Carry the window along while `Super` is held, and drop it where you let go |
| `Super+Ctrl+Escape` | Float the window above the strip, or put it back |
| `Super+Alt+Escape` | Hide or show the floating windows |
| `Super+Shift+C` | Where the strip scrolls a focused window to: into view, centre, edge |
| `Super+Shift+W` | Where new windows open: right, left, below |
| `Super+N` | A new window of the app you are in |
| `Super+Ctrl+B` | Hide or show the top bar on this workspace |
| `Super+Backspace` | Resize the window with the arrow keys |
| `Super+W` | Close the window |
| `Shift+F11` | Full screen, keeping the title bar |
| `Super+H` | Minimise the window |

## Workspaces

Six fixed workspaces, so a number always means the same one. The one you are on is highlighted in
the top bar on the left.

| Key | Action |
| --- | --- |
| `Super+1` … `Super+6` | Go to that workspace |
| `Super+Shift+1` … `Super+Shift+6` | Take the window there |
| `Super+Page Up` / `Page Down` | The previous / next workspace, with its card shown in a row |
| `Super+Ctrl+Page Up` / `Page Down` | Take the window to the previous / next workspace |
| `Super+Shift+Left` / `Right` / `Up` / `Down` | Focus the monitor in that direction |
| `Super+Shift+Ctrl+Left` / `Right` / `Up` / `Down` | Move the window to that monitor |
| `Super+Alt+Left` / `Right` / `Up` / `Down` | Swap this monitor's workspace with the one the monitor in that direction shows |
| `Ctrl+Alt+Shift+Left` / `Right` / `Up` / `Down` | Move this monitor's workspace to the monitor in that direction |
| `Super+Ctrl+Alt+Left` / `Right` | Swap this workspace with the one beside it, windows and name included |
| `` Super+Ctrl+` `` | Take the window to the workspace you were on before; each further press goes one more back, round again at the end |
| `Ctrl+Alt+1` … `Ctrl+Alt+9` | Go to the pinned app in that dock slot |
| `Super+Tab` / `Alt+Tab` | Switch application / window; type to filter (classic layout) |
| `` Super+` `` | Switch between the windows of the app you are in |
| `Super+Z` | Snap layouts for the focused window (classic layout) |
| `Super+Alt+Return` | The drop-down terminal, and the scratchpad's windows in the classic layout |
| `Super+Alt+P` | Keep the window on top, with a ring and a pin, or let it go |
| `Super+Alt+T` | Reopen the app you just closed, at its place; five back |
| `Super+Alt+Home` | Leave the simple desktop, while it is on |
| `Super+Alt` and scroll | See through the window under the pointer, while see-through windows are on |
| Hold `Super` | The main shortcuts, and numbers on the dock |

## Launching

The keyboard shortcuts that open things: the search, a terminal, the browser, Files and Amethystora's
own apps.

| Key | Action |
| --- | --- |
| `Super+Space` | Search and launch |
| `Ctrl+1` … `Ctrl+9`, `Space` | In the search: open the result with that number; `Space` on a file shows it without opening it |
| `Super` | The overview: every open window, and search |
| `Super+A` | Every installed app |
| `Alt+F2` | Run one command |
| `Super+Return` | Terminal |
| `Ctrl+Alt+T` or `Ctrl+Alt+Return` | Terminal, the way most Linux desktops open it |
| `Super+Shift+B` | Browser |
| `Super+Shift+F` | Files |
| `Super+E` | Home folder |
| `Ctrl+Shift+Esc` | Mission Center, to see and stop what is running |
| `Super+.` | Emoji and symbols over the window you are typing in |
| `Ctrl+Alt+Space` | Smile, the emoji app |
| `Super+Ctrl+Shift+A` | An AI agent that knows this system, once you turn it on (`ame agent toggle on`) |
| `Super+Shift+A` | Ask the AI agent about the text selected in any window, while it is on |
| `Super+/` | Ask the AI agent a question in the pill's card, while it is on: it answers there, with no terminal |
| `Super+Ctrl+Shift+C` | Control: the theme, windows, games, the agent, the image and Amethystora's other settings |
| `Super+F1` | This manual |
| `Super+Alt+N` | A quick note into Notes' inbox |
| `Super+Alt+D` | Draw on the screen, while Present mode is on (`ame desktop present on`) |
| `Super+Alt+C` | Pick a colour from the screen: a click copies it as hex, `Shift`+click as rgb(), `Ctrl`+click as hsl() |
| `Super+Alt+M` | Mute the microphone in every app, or turn it back on |

## Appearance

| Key | Action |
| --- | --- |
| `Super+Alt+Space` | The Amethystora menu |
| `Super+Ctrl+Shift+Space` | Pick a theme |
| `Super+Ctrl+T` | The next theme, round again at the end |
| `Super+Ctrl+Space` | Next wallpaper for this theme |
| `Super+Ctrl+D` | Switch between the light and dark theme |
| `Super+Ctrl+R` | Show or hide the reading ruler, once you choose one (`ame desktop access ruler band`) |
| `Super+Ctrl+S` | Read the selected text aloud, or stop, once you turn it on (`ame desktop access read-aloud on`) |
| `Super+Alt+K` | Letters on the window's buttons and links, to click them by typing, once you turn it on (`ame desktop access letters on`) |
| `Super+Ctrl+Shift+D` | Dictate into the text field in use, or stop, once you turn it on (`ame desktop dictation on`) |
| `Super+Ctrl+P` | The pen's tools, once you turn them on (`ame desktop touch pen-ring ring`) |

The same from a terminal: `amethystora-theme list`, `amethystora-theme set <name>`,
`amethystora-theme next`, `amethystora-theme bg next`, or `ame desktop theme`.

## The desktop

| Key | Action |
| --- | --- |
| `Super+V` | Notifications and the calendar |
| `Super+Shift+V` | The clipboard history |
| `Super+Alt+V` | Paste what is copied as plain text, without its fonts, colours and links |
| `Super+L` | Lock the screen |
| `Super+D` | Show the desktop |
| `Print` | Take a screenshot or record the screen |
| `Ctrl+E`, in the screenshot bar | Copy the text out of the selected area (Gradia) |
| `1` … `9`, in the screenshot bar | Pick a drawing tool |
| `Ctrl+Z`, in the screenshot bar | Undo the last mark |
| `Ctrl+C`, in the screenshot bar | Copy the picture without saving it |
| `Ctrl+S`, in the screenshot bar | Save the picture where you choose |
| `Ctrl+Shift+Alt+R` | Open the screen recorder (`Enter` starts), or stop a recording |
| `Super+Shift+Space` | Next keyboard layout, when you have more than one |
| `Super+Escape` | Take the keyboard back from an app that grabbed it, such as a virtual machine |
| `Super+Ctrl+Shift+Esc` | Force quit: the running apps with what each uses, and end the one that hangs |

In every Amethystora app (Security, Updates, Logs, Notes, Backups, Control and this manual), `Ctrl+=`,
`Ctrl+-` and `Ctrl+0` change the size of everything in the window, and in all but this manual `Ctrl+R`
or `F5` reads it all again. Starting one that is open already brings its window forward, at the page
asked for.
