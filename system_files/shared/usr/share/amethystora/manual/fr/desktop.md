# Se repérer

Le bureau est GNOME, organisé pour le clavier. Tout ce qui suit fonctionne aussi à la souris, mais une
fois les raccourcis dans les doigts, vous la toucherez rarement.

## Extensions

Ces extensions de GNOME Shell sont fournies avec l’image :

| Extension | Ce qu’elle fait |
| --- | --- |
| Amethystora Clipboard | L’[historique du presse-papiers](clipboard.md#the-clipboard) sur `Super+Shift+V`, chiffré : une copie de Clipboard Indicator |
| Amethystora UI | Le bureau d’Amethystora, écrit pour cette image : la [mosaïque](tiling.md), les fenêtres côte à côte sur une bande qui défile, le dock, le verre dépoli derrière le panneau, la vue d’ensemble, les menus et les notifications (les fenêtres que vous n’utilisez pas sont rendues légèrement transparentes), les espaces de travail, les indicateurs et les icônes de la zone de notification dans la barre supérieure, une icône de téléphone tant qu’un [téléphone associé](wireless.md#phones) est connecté, la recherche sur `Super+Space`, une recherche d’applications qui pardonne les fautes de frappe, le dessin sur une capture d’écran et la [copie de son texte](screenshots.md#copying-text-from-the-screen), la désinstallation d’une application depuis son menu, des animations plus rapides, pas de fenêtre surgissante quand vous changez d’espace de travail, et pas de bouton Activités |
| Menu du logo | Le logo Amethystora en haut à gauche et [son menu](top-bar.md) d’outils système |
| Amethystora Transitions | L’animation qui dévoile un nouveau thème ou fond d’écran ([Transitions](wallpapers.md#transitions)) |
| Amethystora Widgets | Vos propres [widgets](widgets.md) dans la barre supérieure ; rien tant que vous n’en ajoutez pas |

Désactivez n’importe laquelle, ou modifiez ses paramètres, dans **Extensions** (le Gestionnaire
d’extensions sert à en trouver de nouvelles sur extensions.gnome.org, qui n’a aucune de celles-ci). Une
chose à savoir : après chaque mise à jour de l’image, les extensions propres à l’image sont réactivées,
pour qu’une extension désactivée par accident, ou par un plantage, ne le reste pas définitivement. Une
désactivation dure jusqu’à la mise à jour suivante. La [disposition classique](tiling.md#classic-windows) n’est pas
une extension désactivée : elle reste comme vous l’avez choisie.
