# Sich zurechtfinden

Der Desktop ist GNOME, für die Tastatur eingerichtet. Alles hier funktioniert auch mit der Maus, aber
sobald Ihnen die Tasten in Fleisch und Blut übergegangen sind, greifen Sie nur noch selten zu ihr.

## Erweiterungen

Diese GNOME-Shell-Erweiterungen sind im Abbild enthalten:

| Erweiterung | Was sie tut |
| --- | --- |
| Amethystora Clipboard | Der [Verlauf der Zwischenablage](clipboard.md#the-clipboard) auf `Super+Shift+V`, verschlüsselt: eine Kopie von Clipboard Indicator |
| Amethystora UI | Amethystoras eigener Desktop, für dieses Abbild geschrieben: [Kacheln](tiling.md), Fenster nebeneinander auf einem scrollenden Streifen, das Dock, das Milchglas hinter der Leiste, der Übersicht, den Menüs und den Benachrichtigungen (Fenster, die Sie gerade nicht benutzen, werden leicht durchscheinend), die Arbeitsflächen, die Anzeigen und die Statussymbole in der oberen Leiste, ein Telefonsymbol, solange ein [gekoppeltes Telefon](wireless.md#phones) verbunden ist, die Suche auf `Super+Space`, eine App-Suche, die Tippfehler verzeiht, Zeichnen auf einem Bildschirmfoto und das [Kopieren seines Textes](screenshots.md#copying-text-from-the-screen), das Deinstallieren einer App aus ihrem Menü, schnellere Animationen, keine Einblendung beim Wechsel der Arbeitsfläche und keine Aktivitäten-Schaltfläche |
| Logo-Menü | Das Amethystora-Logo oben links und [sein Menü](top-bar.md) mit den Werkzeugen des Systems |
| Amethystora Transitions | Die Animation, die ein neues Thema oder Hintergrundbild enthüllt ([Übergänge](wallpapers.md#transitions)) |
| Amethystora Widgets | Ihre eigenen [Widgets](widgets.md) in der oberen Leiste; nichts, bis Sie eines hinzufügen |

Schalten Sie jede davon in **Erweiterungen** aus oder ändern Sie dort ihre Einstellungen (die
Erweiterungsverwaltung ist dafür da, neue auf extensions.gnome.org zu finden, wo es keine von diesen
gibt). Eines sollten Sie wissen: Nach jeder Aktualisierung des Abbilds werden die eigenen Erweiterungen
des Abbilds wieder eingeschaltet, damit eine, die versehentlich oder durch einen Absturz ausgeschaltet
wurde, nicht für immer aus bleibt. Das Ausschalten einer Erweiterung hält bis zur nächsten
Aktualisierung. Das [klassische Layout](tiling.md#classic-windows) ist keine ausgeschaltete Erweiterung und
bleibt daher so, wie Sie es eingestellt haben.
