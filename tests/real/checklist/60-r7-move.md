# Round 7, move: Send to nearby, Move to this computer, Bring everything from your old computer, Send to anyone

Walk on a real machine running the image with round 7, as a person would. The spec is `plans/ui-ideas/r7/spec-move.md`. Mark
each line as the other files do: `→ PASS`, `→ FAIL: what was seen`. Most of this needs a second computer, a phone or an old disk,
which the machine this was built on lacks: those lines say what is needed. What was proved without them is in cargo
(`cargo test -p amethystora-connect -p amethystora-move`) and in `build_files/shared/test-bring-over.sh` and `test-send-anyone.sh`,
which `20-tests.sh` runs.

## R7-48 Bring everything from your old computer

- [ ] R7-MOVE-20 An old Windows disk. How: plug an NTFS disk of a Windows computer (a case or a dock), `ame system bring-over`. Expect: it is listed with its label and size, only if it was plugged in (not this computer's disks, a pool, an `/etc/fstab` disk or an internal one); choosing it mounts it read-only (`findmnt -o TARGET,OPTIONS` shows `ro`, and `noload` for ext4), lists the person and each folder with its size, and copies what is ticked into Documents, Pictures, Music, Videos, Desktop and Downloads; the disk is unmounted at the end. [needs: a disk of another computer] → NOT DONE: needs an old disk (the stand-in test covers a Windows-shaped tree, the stubs and the terminal flow)
- [ ] R7-MOVE-21 A BitLocker disk. How: plug one, choose it. Expect: it asks for the recovery key with nothing showing; with the right key it unlocks and goes on; with a wrong one it says the disk did not unlock; the key is in no argument (`ps -ef | grep udisksctl` while it works), file or journal (`journalctl -b | grep KEY`). The disk is locked again at the end. [needs: a BitLocker disk and its recovery key] → NOT DONE: needs a BitLocker disk (udisks's `--key-file /dev/stdin` against a real one has not been tried)
- [ ] R7-MOVE-22 Nothing on the disk changes. How: `find DISK -printf '%p %s %T@\n' | sort | sha256sum` before and after; try `touch DISK/x` while it is mounted. - [ ] R7-MOVE-23 No password is read. [needs: an old disk] → NOT DONE: needs an old disk (the stand-in test has unreadable logins and canaries, and passes)
- [ ] R7-MOVE-24 It carries on. How: stop with Ctrl+C in the middle of Pictures; run again. Expect: no half files, and it carries on with what is missing; a file whose name is already here is kept. [needs: an old disk] → NOT DONE: needs an old disk
- [ ] R7-MOVE-25 An APFS disk and a LUKS one. How: plug each. Expect: listed, with "This format cannot be read here." and the way to unlock a LUKS one first; choosing them stops at once. [needs: such disks] → NOT DONE: needs such disks
