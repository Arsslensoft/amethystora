# Round 7, agent: What it is doing, Ask right there, Yes or no, Ask about this, Little routines

Walk on a real machine running the image with round 7, as a person would, with the agentic features on (`ame agent toggle on`). The spec is
`plans/ui-ideas/r7/spec-agent.md`. Mark each line as the other files do: `→ PASS`, `→ FAIL: what was seen`. "Headless" means the shell of a
throwaway stand-in home on the real machine (GNOME Shell 51, the worktree's extension, the real tool server built from it); a Vault was never set up
there, so what needs one is not done.
