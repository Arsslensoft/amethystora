# Round 7, keep: Put this away, Charged by the time you leave, Start from your backup, Back up to your other computer

Walk on a real machine running the image with round 7, as a person would. The spec is `plans/ui-ideas/r7/spec-keep.md`. Mark
each line as the other files do: `→ PASS`, `→ FAIL: what was seen`. Items marked `(headless, 2026-11-06)` were tried in a throwaway GNOME Shell with
a stand-in Vault (a socket that really encrypts, never the live one) on the real machine; `NOT DONE` needs hardware or a second computer this machine lacks.
Every item that says "the Vault" means the Vault of the account you test with: set it up first (Vault, **Set up**), and for the nightly backup turn on its
background key.

- [ ] R7-KEEP-26 Your own limit is yours. How: set GNOME Settings' battery limit by hand, then turn this on and plug in. Expect: nothing here changes it, and it is never taken off by this. [needs: a laptop] → NOT DONE: needs a laptop
- [ ] R7-KEEP-27 Off gives everything back. How: while held, `ame desktop power charge off`. Expect: the limit this turned on is taken off, and the marker file `~/.local/state/amethystora/charge-by-hold` is gone. → PASS (headless, 2026-11-06) with a stand-in UPower
