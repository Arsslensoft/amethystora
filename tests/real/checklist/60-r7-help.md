# Round 7, help: Something's wrong, Show me, What changed, Back in time

Walk on a real machine running the image with round 7, as a person would. The spec is `plans/ui-ideas/r7/spec-help.md`. Mark
each line as the other files do: `→ PASS`, `→ FAIL: what was seen`.

## R7-36 Something's wrong

- [ ] R7-HELP-01 It is in the menu. How: open the Amethystora menu at the left of the top bar, press **Something's wrong**. Expect: the Help window, on its page, with seven plain choices and nothing changed yet.
- [ ] R7-HELP-02 Muted. How: mute the output, pick **No sound**. Expect: "Sound is muted.", **Turn sound on** with `ame system sound unmute` written under it; pressing it unmutes, and it looks again and says sound is on. [needs: sound card]
- [ ] R7-HELP-03 The wrong output. How: plug a screen with speakers, choose it as the output, pick **No sound**. Expect: names the screen, offers **Use "the speakers"** with `ame system sound use ID`; pressing it moves the sound. [needs: an HDMI or DisplayPort screen with sound]
- [ ] R7-HELP-04 Sound program stopped. How: `systemctl --user stop wireplumber.service`, pick **No sound**. Expect: **Start it again**, which brings sound back.
- [ ] R7-HELP-05 No internet, Wi-Fi off. How: turn Wi-Fi off with nothing wired, pick **No internet**. Expect: "Wi-Fi is turned off", **Turn Wi-Fi on**, `ame system network on`; pressing it connects. [needs: Wi-Fi]
- [ ] R7-HELP-06 The router's line down. How: unplug the router's uplink, pick **No internet**. Expect: says NetworkManager's check did not get through, what it saw (the router answered a test message; a name could or could not be found) and that restarting the router "may" help; no button, and nothing blamed as fact. Packets leave only for the router (one ping) and, with the connectivity check on, the one name that check fetches (`sudo tcpdump -ni any` while it looks): never `amethystora.org`, and no name at all with `ame security connectivity-check off`. With the internet working it asks the network nothing at all. [needs: a router you can unplug]
- [ ] R7-HELP-06b A router that ignores pings, a gateway-less link, IPv6 only. How: working internet behind a router that drops ICMP (or block it with `sudo nft`), pick **No internet**; then the same over a phone's USB tethering or a modem (a default route with no gateway). Expect: "NetworkManager says the internet works" each time, no button, no "cannot reach your router". [needs: a router or firewall rule that drops pings]
- [ ] R7-HELP-06c Connecting again says what it ends. How: with a VPN up and an SSH session open, make No internet offer **Try to connect again** (turn the router's uplink off and on a network with no way out), press it. Expect: a terminal opens first, says "This turns every connection off for a moment: a VPN, a remote session or a call would end." and waits for Enter; Ctrl+C leaves everything up. With the internet fine the button is never offered. The same for **No sound**: **Start it again** says "This stops all sound for a moment, a call included." first, and is not offered while sound is going to an output. [needs: a VPN]
- [ ] R7-HELP-07 Encrypted DNS blocked. How: `ame security dns` on, on a network that blocks port 853, pick **No internet**. Expect: says so and offers only **Open Security**, on Network; nothing is switched. [needs: a network that blocks 853]
- [ ] R7-HELP-08 A paused printer. How: `cupsdisable NAME`, pick **The printer**. Expect: names it, **Resume printing** opens a terminal with `ame system printer resume NAME`, after which it prints. [needs: a printer]
- [ ] R7-HELP-09 No printer. How: on a machine with none, pick **The printer**. Expect: **Open printer settings** opens Settings on Printers, the button is usable again at once, and a minute later the window does not say "That did not work" while Settings is open.
- [ ] R7-HELP-10 It feels slow. How: run `stress-ng --cpu 1` or a busy loop in a terminal, pick **It feels slow**. Expect: names the program in a sentence, no button; stop it, press again: "No program was using much of the processor in the last second". A program that was busy earlier and is idle now (a long compile that has finished) is not named.
- [ ] R7-HELP-11 Power Saver. How: choose Power Saver, pick **It feels slow**. Expect: **Use the balanced mode**, `ame system power-mode balanced`, which changes it in quick settings.
- [ ] R7-HELP-12 Security only opens Security. How: `ame security usb on`, pick **A device does nothing**. Expect: **Open Security**, on Devices, "may be keeping this device out", and USB protection still on after looking and after pressing. With `ame security usb locked` the words are about the locked screen and do not say new devices are kept out.
- [ ] R7-HELP-12b Unreadable disk. How: with `df` failing for the home (a stale mount) or in a container, pick **Running out of room**. Expect: "could not read how full the disk is", never "0% full".
- [ ] R7-HELP-13 Something else. How: pick **Something else** on a healthy machine. Expect: an answer within about ten seconds, and the spinner shows at once.
- [ ] R7-HELP-14 Nothing kept. How: give the output the name `CANARY-R7-36` (`wpctl set-default` to it after renaming in Settings, or a null sink named so), pick **No sound**, close the window, then `grep -r CANARY-R7-36 ~ /tmp 2>/dev/null; journalctl --user -b | grep CANARY-R7-36`. Expect: nothing found, and the same for `journalctl -b | grep CANARY-R7-36` as an administrator.
- [ ] R7-HELP-15 Closed, nothing runs. How: with the window closed, `pgrep -af 'amethystora-(help|wrong)'`. Expect: nothing.

## R7-61 Show me, on my screen

- [ ] R7-HELP-20 A ring round the real button. How: `Super+F1`, **Hardware**, Turn off Bluetooth, press **Show me**. Expect: the Manual gets out of the way, a ring round the top right menu, a card saying step 1 of 2, under the ring, in the theme's colours. [needs: Bluetooth]
- [ ] R7-HELP-21 It moves on by itself. How: open the menu the ring is round. Expect: the card moves to step 2 and the ring to the Bluetooth button inside the menu. It presses nothing: Bluetooth changes only when you press it.
- [ ] R7-HELP-22 Closing the menu. How: on step 2 press Escape. Expect: the ring goes back round the menu, and opening it brings it back to the button.
- [ ] R7-HELP-23 Back to the manual. How: press **Back to the manual**. Expect: ring and card gone, the Manual on that section, and in front (it was minimized when the guide began and the shell brought it back). Say what was seen under Wayland with no activation token.
- [ ] R7-HELP-23b The Manual comes back whichever way the guide ends. How: start a guide and press **Done** on its last step; start one and `gdbus call --session --dest org.gnome.Shell --object-path /org/amethystora/Guide --method org.amethystora.Guide.Stop`; start one and lock then unlock; start one and, from the Manual, start another. Expect: the Manual in front after each (after the second guide ends, not between). A Manual you had already brought back yourself is left where it is.
- [ ] R7-HELP-23c The ring follows the page. How: on the Backups step, change the page in the app so the button is no longer there, then back. Expect: the ring leaves within a few seconds and comes back round the button; scroll the button out of view in a long page: no ring outside the window.
- [ ] R7-HELP-23d The ring needs the app focused. How: on an app step, click another window (on the default tiling layout too), scroll the strip. Expect: no ring anywhere, the card offers **Open {app}**; focus the app again: the ring is right. During the overview no ring draws.
- [ ] R7-HELP-23e Only the app's own buttons. How: `gdbus call --session --dest org.amethystora.Backups --object-path /org/amethystora/Where --method org.amethystora.Where.Find 'a file name shown in the list'` and the same with a label inside a page's text and with `Status` while Backups shows another page. Expect: zeros for a file name or text; the button's place only for a name in the app's own catalog on a button in view. With Notes locked and then unlocked, a note title gets zeros.
- [ ] R7-HELP-24 In an app. How: `Super+F1`, the backups section, **Show me**. Expect: the card offers **Open Backups**; pressed, Backups opens and the ring finds **Status** in its sidebar; after you press it and **Next**, the ring finds **Set up a backup…** (or the words if a backup is already set up).
- [ ] R7-HELP-25 A window that moves. How: while a ring is on a button in an app, drag the window. Expect: the ring goes with it. Resize it: the ring is right again within a second.
- [ ] R7-HELP-26 A scale other than one. How: repeat R7-HELP-24 at 150% and at 200%. Expect: the ring sits on the button. [needs: a screen to scale]
- [ ] R7-HELP-27 In another language. How: in French, repeat R7-HELP-20 and R7-HELP-24. Expect: the card's words in French where translated, and the ring still finds the widget by its translated name.
- [ ] R7-HELP-28 A step it cannot find. How: on R7-HELP-24 with **Status** nowhere (open the Status page's dialog, or close the app's sidebar by narrowing), wait 30 seconds. Expect: "I cannot point at this one here", with **Back to the manual**.
- [ ] R7-HELP-29 Lock while walking. How: lock during a guide, unlock. Expect: no ring or card left, the shell fine.
- [ ] R7-HELP-30 Off. How: `ame desktop show-me off`, press **Show me** in the Manual. Expect: no ring, the Manual's page shows a note "Show me is off here: ame desktop show-me on" with **Close** (and the Manual is not minimized); the page's words are all there. `gdbus introspect --session --dest org.gnome.Shell --object-path /org/amethystora/Guide` finds nothing. On again: `ame desktop show-me on`.
- [ ] R7-HELP-31 Idle. How: no guide running, `pgrep -af 'amethystora-(help|wrong|changes)'`. Expect: nothing, and no process of its own during a guide either.
- [ ] R7-HELP-32 Control. How: Control, **Desktop**, **Help**, **Show me, on my screen**. Expect: the switch follows `ame desktop show-me` and its manual link opens the section.

## R7-32 What changed

- [ ] R7-HELP-40 A deleted file. How: put `Taxes CANARY-R7-32.txt` in Documents, delete it in Files, press **What changed** in the Amethystora menu. Expect: "You deleted ..." under Today, **Undo** brings it back to Documents, and the line goes.
- [ ] R7-HELP-41 It never overwrites. How: delete `a.txt`, make a new `a.txt`, Undo the first. Expect: both there: `a.txt` as it is, and `a (restored).txt`.
- [ ] R7-HELP-41b Only into your own files. How: delete `~/.config/autostart/x.desktop` and `~/.bashrc.test` in Files, then write by hand a trash entry whose `Path=` is `/tmp/CANARY-R7-32.txt`, `../../../tmp/CANARY-R7-32.txt` and `~/.config/autostart/evil.desktop` (copy a file's `.trashinfo` in `~/.local/share/Trash/info` and edit it). Expect: each line shows with no Undo and says Files can put it back; nothing appears in `/tmp` or in the autostart folder; Files' own Restore still works.
- [ ] R7-HELP-41c A file name that is not text. How: `touch "$(printf 'caf\xe9.txt')"` in Documents, delete it in Files, open the page. Expect: the list still opens; the file's line shows (with a replacement mark in the name), Undo brings back the file under its real bytes (`ls | od -c`). Try on the Fedora 44 stable image and on 45.
- [ ] R7-HELP-41d Undo twice. How: make a setting change older than the last snapshot (a day), press its **Undo**, then look at the page and press anything left for the same setting. Expect: the line goes; the page never offers to do the undone change again. The same for the theme. A second Undo of a file, an app or a snapshot file is refused with "no longer on the list".
- [ ] R7-HELP-42 A file deleted outright. How: with snapshots on, `rm` a file from Documents that is at least an hour old. Expect: "... is gone from Documents" with **Undo**, which brings it back from the snapshot and changes nothing else. [needs: hourly snapshots on, an hour's wait]
- [ ] R7-HELP-43 An app. How: remove a Flatpak app with Uninstall in the app grid, its data going to the trash (R7-41), open the page. Expect: "You removed ...", one line with no separate line for its folder; **Undo** opens a terminal that installs it and its folder comes back from the trash, so it opens with what it had saved. An app just installed is listed ("... was installed") with no Undo. An app removed with `flatpak uninstall` shows too, for an account that can read the system journal, as "... was removed" (Flatpak's history is the machine's, so it does not say you), and its Undo says it installs it again from where it came from. With `flatpak` unable to list (break it), no app is called removed. [needs: R7-41 merged, a network]
- [ ] R7-HELP-44 A setting. How: with snapshots on and at least one taken, `ame desktop dock edge left`, open the page. Expect: "The dock moved", **Undo** moves it back. Wallpaper and theme likewise. [needs: hourly snapshots on]
- [ ] R7-HELP-45 An update. How: on a machine with a previous deployment. Expect: "The system updated", naming both versions; **Undo** opens a terminal, asks an administrator's password and makes the previous one the next start. Put it back after. [needs: a previous deployment]
- [ ] R7-HELP-46 Security. How: `ame security firewire off`, wait for the watcher (15 minutes, or run it), open the page as an administrator. Expect: "A security setting changed" with only **Open Security**. Put it back: `ame security firewire on`.
- [ ] R7-HELP-47 Snapshots off. How: on a machine with them off, open the page. Expect: a note that a file deleted outright and a setting as it was need the snapshots, and **Open Security**; trash and apps still listed.
- [ ] R7-HELP-48 Nothing stored. How: after R7-HELP-40, close the window, then `grep -r CANARY-R7-32 ~/.local/state ~/.config ~/.cache /tmp 2>/dev/null; journalctl --user -b | grep CANARY-R7-32; sudo journalctl -b | grep CANARY-R7-32; ls ~/.local/state/amethystora | grep -i -E 'change|help'`. Expect: nothing found.
- [ ] R7-HELP-50 The agent's change. How: with level 2 on, have the agent change a Control entry, open the page and press **Undo**; change another, then `ame agent toggle off` and open the page. Expect: "The AI agent changed ...", undone by the tools' own undo, after which the line is gone and no second line for the undoing appears (the tools write the undoing as a record with `of`, in `~/.local/state/amethystora/agent-tools/actions.jsonl`); with the features off no such line, and with only level 1 (`ame agent tools off`) none either. An app the agent installed through its `software` tool has no line with Undo. [needs: an agent]
- [ ] R7-HELP-50b The agent cannot press Undo. How: ask the agent to run `amethystora-changes undo trash:x.trashinfo` through its `run` tool. Expect: refused by the tools' never list; `amethystora-changes list --json` is allowed.
- [ ] R7-HELP-49 Speed. How: with a full trash (100 items), and snapshots on, open the page. Expect: the page and its spinner at once, the list within a few seconds, the desktop never stalling.

## R7-28 Back in time, visibly

- [ ] R7-HELP-60 It is offered. How: Backups with at least two points, browse. Expect: the window opens as it always did, with **Back in time** among the folder's tools.
- [ ] R7-HELP-61 The windows. How: press **Back in time** in Documents. Expect: the folder as the front window, up to three smaller, fainter windows behind it each named for its point, the timeline still at the side, at the theme's colours.
- [ ] R7-HELP-62 Scrolling. How: turn the wheel slowly, then fast; Page Down and Page Up; click a window behind; click a point on the timeline. Expect: the windows step smoothly, the folder there comes in when the walk settles, the timeline's point follows, and the desktop never stutters. With a backup among the points its folder takes longer to come and the view stays usable.
- [ ] R7-HELP-63 Reduce motion. How: turn animations off in Settings, Accessibility, repeat. Expect: the windows stand in their new places with no motion.
- [ ] R7-HELP-64 Put this back. How: at an earlier point where a file differs, press **Put this back…**. Expect: a question first (nothing is deleted or replaced; a different file keeps its place and the earlier one comes back beside it with its date in its name); **Put the folder back** does that (`ls` the folder before and after).
- [ ] R7-HELP-64b The list on screen is the point chosen. How: with a backup among the points (slow `ls`), walk to it with the wheel and, before the list changes, try **Put back**, **Look** and **Put this back…**. Expect: they are dimmed until the folder of that point is shown; none acts on a point other than the one shown. [needs: a restic backup]
- [ ] R7-HELP-65 The list inside. How: tick a file in the front window, **Put back**, **Versions**, **Look**; open a folder from it. Expect: each as in the normal list.
- [ ] R7-HELP-66 Leaving. How: **Back to the list**, or Escape; or turn the wheel and at once press **Back to the list**; or open **Status** and come back. Expect: the window exactly as it was, the point never moving after you left, the view off after Status, and with the view never opened the Browse page behaves as before.
- [ ] R7-HELP-67 In right to left. How: in Arabic, repeat R7-HELP-61. Expect: the windows centred, the timeline at the inline end.
- [ ] R7-HELP-68 Nothing kept. How: make a folder `CANARY-R7-28` in Documents, browse into it in the past view, close, then `grep -r CANARY-R7-28 ~/.local/state ~/.config ~/.cache /tmp 2>/dev/null; grep -c past ~/.local/state/amethystora/backups.json 2>/dev/null; pgrep -af 'amethystora-restore'`. Expect: nothing of it kept (the window may keep the folder it was left on, as it always did, but never that the past view was on), and nothing running.
